# Cash Tracker

## Mode Kerja
Always create a plan in `.hermes/plans/` before implementing any code. Wait for explicit user confirmation ("lanjut", "eksekusi", "gas") before executing.

## AI Rules
Ikuti aturan di `docs/AI RULES.md` secara ketat, terutama:
- **KISS, DRY, SOLID** — jaga kode tetap sederhana
- **Pahami masalah dulu** sebelum nulis kode
- **Jangan modifikasi kode yang tidak terkait**
- **Gunakan kode yang sudah ada** — hindari duplikasi
- **Hormati arsitektur proyek** — jangan rename folder/pindah file
- **Error handling** — jangan abaikan error
- **Security** — validasi input, jangan hardcode secret
- **Output format:** Analysis → Root Cause → Solution → Files → Risks → Implementation → Self Review
- **Self review** sebelum selesai: correct? simplest? no duplication? follow style? break existing?
